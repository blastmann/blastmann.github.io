今天最值得看

1. WebFovea：模型判断对了，浏览器动作却执行错了（10 月 7 日，补推）

WebFovea 在 WebRetriever Challenge 2026 获得 57.0/100、排名第二。作者把 Browser Agent 一次操作拆为输出解析、页面执行、结果反馈、下一轮观测四个环节。真实故障包括坐标变换错误，所有点击落在目标坐标的 3/4；iframe、原生下拉框与输入框的静默失败；聊天模板标记混入文本框，影响 4.9% 的任务轮次。

在保持模型不变的四次竞赛提交中，隐藏测试成绩从 31.0 提升至 57.0，说明 Harness 修复可能比换模型更有效，但真实网站存在波动，不能完全归因于单一改动。建议 Browser Runtime 保存 intended_action、resolved_target、executed_action 和 observed_delta，逐层检查，而不是相信模型声称“操作成功”。

原论文 · 开源代码 · 作者补充案例

2. Windows Browser Agent：可见页面与实际控制链路分离（10 月 12 日）

Codex Windows 桌面端的公开问题 #53306 报告：内嵌浏览器可显示页面，Chrome 设置也正常，但 browser-control 子 Agent 看不到浏览器；#53332 则记录 Browser Client 在 MXC 沙箱中加载时，realpath 返回 EPERM，连接尚未建立。同日 #53349 记录一例只读购物任务可能遭遇错误网站安全分类。它们分别指向发现、运行环境与策略三个层次，没有证据证明共同根因。

工程上应把 provider_discovered、sandbox_ready、target_attached、policy_granted、action_verified 分开观测；技术故障与权限拒绝使用不同错误码。不能因为浏览器不可用而绕过安全策略。

#53306 · #53332 · #53349

3. Safari Technology Preview 254：WebGPU 与 WebDriver 生命周期修复（10 月 8 日，补推）

WebKit 官方确认修复 WebGPU device lost 后异步 pipeline 创建 Promise 永不结束、重复使用 GPUShaderModule 时 pipeline shader cache 失效、少数慢帧导致长期低帧率等问题。WebDriver Classic 命令改为按会话串行，修复并发命令与导航等待造成的挂起；WebDriver BiDi 开始支持视口截图。

这些都是 Browser Agent 和端侧推理稳定性的重要边界。WebKit 还报告 WebAssembly in-place 解释器在 Apple silicon 上约 5% 的性能改善，并支持 WebCodecs 部分构造器的 transfer 选项及 HEVC Annex B 编码。此为 Technology Preview 更新，不代表稳定版 Safari 已全部具备。

WebKit 官方发布说明

4. Transformers.js 4.3.1：本地多模态 Embedding（10 月 7 日，补推）

Transformers.js 4.3.1 增加 EmbeddingGemma 2 支持。官方示例可在 WebGPU 或 WASM 上运行量化模型，把文本、图片、音频、视频映射到统一的 768 维向量空间；模型合计约 740M 参数。对浏览器短期兴趣记忆，可以本地编码商品文本与图片，先检索少量候选，再交给云端模型分析。

需要实测模型下载、缓存恢复、GPU 内存峰值、页面 FPS、手机发热与召回质量。向量相似度不是同款商品的最终证明，也不能成为 Agent 获得操作权限的依据。

官方 Release · GitHub

Round-Trip Contract Before Learning：先验证动作往返链路，再积累经验

迁移建议：为每次浏览器操作保存 browser/harness revision、session_id、frame_id、坐标系、权限决定、动作回执和页面前后差异。优先建立 iframe、缩放、原生 select、导航、GPU device lost 与 WebDriver 并发的可执行回归测试。候选 Agent 可以优化动作与诊断流程，但不得修改独立的最终验收标准。

今天的一个判断

Browser Self-Improvement 首先要证明“Agent 想做的动作”和“浏览器实际发生的动作”一致。 如果坐标、执行、反馈或权限状态本身不可靠，自动诊断与 Learn 可能把 Harness 错误写成浏览器经验。优先投资可回放的动作回执与分层验证，而不是继续增加提示词。
