今天最值得看

1. HTML-in-Canvas：把真实 HTML 绘制到 GPU 场景（此前已发布，重要技术补推）

新机制：浏览器通过 layoutsubtree、drawElementImage、texElementImage2D、copyElementImageToTexture 和 paint 事件，将 DOM 内容作为 Canvas/WebGL/WebGPU 场景的可绘制来源，而不只是把 DOM 覆盖在 Canvas 上。它有潜力改变空间浏览器、3D UI 和 AI 生成界面的渲染结构。状态：Edge Origin Trial，非正式跨浏览器标准；试验到 2027-03-02，不能宣称 Safari/Firefox 已支持。工程验证：需要重点测试输入事件映射、无障碍语义、纹理刷新、跨帧资源成本。来源：Edge Origin Trial；Opera 技术介绍。

2. Declarative Performance Observer：浏览器原生遥测（Edge 实验能力，非今日首发）

新机制：由 HTTP 响应头声明性能观察需求，浏览器负责从导航开始到页面终止的采集，减少 JS 初始化晚、页面关闭时数据丢失等问题。与 JS Self-Profiling Markers、Speculative Load measurement 一同值得研究。状态：Origin Trial/实验性 API，不等于稳定跨浏览器支持。工程价值：为 Browser Self-Improvement 提供比页面自报更独立的性能观测；优先测试生命周期完整性、隐私与上报开销。来源：Edge 官方发布说明。

3. Firefox 160：WebTransport 与本地语音能力（11 月 10 日发布，7 日补推）

新能力：WebTransport 支持在扩展 CONNECT 建立阶段传递自定义 HTTP Header，并暴露响应 Header；同版本还带来本地语音识别相关进展。为什么重要：浏览器端实时语音 Agent 同时依赖低延迟双向传输和端内语音处理。验证：需确认不同操作系统的本地识别可用性、离线行为、WebTransport 服务端兼容性，不能从版本说明直接推断跨平台统一支持。来源：Mozilla 官方 Firefox 160 开发者说明。

技术深挖候选（非本周新发布）：GPU Goldmines

研究提出针对 WebGPU 矩阵乘、矩阵向量乘与 Flash Attention 的可调优 Kernel 库及跨设备配置选择；论文作者报告矩阵乘几何平均性能优于 ONNX Runtime WebGPU 7.0 倍、优于 llama.cpp WebGPU 1.41 倍，并在 llama.cpp Prefill 中得到 1.48 倍端到端提升。注意：论文首次发布于 10 月，不是今日新闻，且上述是论文实验，不是独立复测。它值得作为后续深度研究主题，而非重复报道的头条。来源：GPU Goldmines 原论文。

浏览器 × AI

Playwright 解决多 Agent 标签归属，agentwatch 提供运行时间线与故障证据，DevTools MCP 候选改动 让网页错误与操作回执关联。三者适合组合为一个受控 Browser Session：控制前验证 Owner，操作期间收集 Console/Network，完成后由独立会话判断效果。

另有 DevTools MCP #3473 提出可选 --repl 批量执行页面操作和检查，试图减少模型轮次与 MCP 往返。目前是Draft PR，未发布，需要额外验证脚本权限、取消和失败后副作用。

今天的一个判断

让 Agent 用上更先进的 Web API 并不难，难的是证明它在 Chrome、Firefox、Safari 上都按预期工作；让多个 Agent 连接真实浏览器也不难，难的是确认每一次操作属于谁、是否真的生效、失败证据能否重放。 这两类基础验证能力，比再增加一层固定 Agent 工作流更值得投入。
