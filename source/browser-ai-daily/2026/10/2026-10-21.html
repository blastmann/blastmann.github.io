今天最值得看

1. Chrome 156 Stable：353 项安全修复，AI 辅助漏洞报告进入真实发布

发生了什么（10 月 20 日）：Chrome 156 正式进入 Windows、macOS、Linux 稳定通道，版本为 Linux 156.0.8078.47、Windows/macOS 156.0.8078.47/.48。官方公告列出 353 项安全修复，涉及 Skia、Accessibility、CSS、Paint、WebRTC、Dawn、ANGLE、V8 等。Critical 级 WebRTC 内存损坏漏洞 CVE-2026-113303 由 OpenAI Codex Security（kylebot）报告；Accessibility 的 CVE-2026-113271 由 Anthropic 研究人员在 Claude 辅助下报告。

为什么重要：AI 参与的漏洞发现已进入有 CVE、组件和稳定版对应关系的工程流程。启发：将最小复现、修复 CL、独立安全回归和发布覆盖率建立关联。不能把 AI 辅助报告等同于 Agent 自主修复。Chrome 官方公告

2. Chrome 156：IndexedDB SQLite 后端与 WebRTC 诊断日志

发生了什么：新建 IndexedDB 数据库开始使用 SQLite 后端，已有 LevelDB 数据暂不迁移，Web API 不变；这是多阶段替换的第二步。WebRTC Diagnostic Logging API 允许授权应用收集本地故障诊断日志，在用户同意后分享给浏览器厂商。WebTransport 新增握手请求头及响应头支持。

为什么重要：影响浏览器本地 AI Memory、离线索引、实时音视频诊断。启发：分别评估新旧 IndexedDB 数据库的崩溃恢复、写入延迟与兼容性；诊断日志必须有授权和脱敏。SQLite 的可靠性提升是设计目标，不是已经独立测得的结果。Chrome 156 平台说明

3. Firefox：证书安全事件后 OneCRL 不到三小时完成标准配置用户防护分发

发生了什么（10 月 20 日官方复盘）：Mozilla 10 月 17 日 20:06 UTC 收到八张 eMudhra 中间证书私钥泄露报告，通过 OneCRL 下发撤销列表，22:59 UTC 完成标准配置 Firefox 用户的防护分发，无需重启或升级。10 月 20 日发布 Firefox 158.0.1 与 ESR 补充版本，覆盖部分特殊配置未收到撤销列表的用户，并更新 NSS 信任列表。

为什么重要：这是 Observe → 紧急缓解 → 远程分发 → 正式版本补充的真实工程闭环。启发：自我改进的 Verify 阶段必须区分“已推送”和“终端实际生效”，为无法接收远程策略的设备准备备用发布路径。Mozilla 官方复盘

4. llama.cpp WebGPU：Prefill 队列过长可能阻塞桌面合成（待合并）

发生了什么（10 月 20 日 PR #30898）：候选补丁将 Prefill 图的在途 Batch 提交数限制为 1，Decode 保持不受限，以避免 GPU 队列长时间阻塞前台渲染。Prefill 检测参考 CLIP patch embedding 和多 Token 的 LLM embedding。作者披露 DeepSeek 4.1 Flash 辅助编写，在 Chromium 155 手工测试，尚未合并。

为什么重要：端侧推理不能只看 tokens/s，还要考虑网页帧率和用户输入延迟。启发：同时采集 Prefill/Decode 吞吐、GPU Queue、dropped frames、交互 P95、设备丢失率，再决定是否推广调度策略。原始 PR

5. Playwright MCP：元素目标错误反馈更准确，支持多语言 Locator（已合并）

发生了什么（10 月 20 日 PR #43539）：当 Agent 传入无效 target 时，MCP 不再只返回晦涩的 CSS 解析错误，而是说明可接受的 ref、CSS selector、Locator 格式；若错误地把 [ref=...] 当成选择器，会提示直接传 ref。Locator 支持 JavaScript、Python、Java、C# 表达式。

为什么重要：工具接口与错误反馈直接影响 Agent 自我恢复。启发：将参数格式错误、引用失效、页面变化和权限拒绝分成不同错误类型，并为工具契约建立回归测试。原始 PR

浏览器 × AI

Chrome DevTools MCP 10 月 20 日 PR #3276 提出可选 configure_webauthn 工具，让 Agent 通过 DevTools 虚拟认证器测试 Passkey 注册、登录、失败验证和已导入测试凭据。工具按 Page 隔离，响应不回显私钥；作者提供真实浏览器 navigator.credentials.create/get 测试。该 PR 尚未合并。启发：身份验证自动化应优先使用隔离、可回放的虚拟认证器，不要直接操作真实用户凭据。原始 PR · 官方文档

Browser Self-Improvement

Distribution-Aware Verification：验证修复在终端真正生效

业界做到哪：Chrome 156 安全问题已走到正式发布，但不能证明全部由 Agent 自主完成；Firefox 证书事件已完成紧急远程策略分发与备用版本发布；Playwright MCP 完成修复合并；WebGPU Prefill 和 DevTools WebAuthn 仍是候选。没有证据证明这些项目已组成一个自主持续学习闭环。

Observe: Crash / CVE / WebRTC Trace / GPU Jank
  ↓ Reproduce + Environment Fingerprint
  ↓ Diagnose / Bisect / Agent Candidate
  ↓ Patch + Independent Regression
  ↓ Build / Benchmark / Review
  ↓ Canary / Remote Policy / Stable
  ↓ Verify Device Coverage / Rollback
  ↓ Archive Evidence / Learn

迁移建议：每个 Chromium 改进实验保存 Browser Revision、最小复现、Culprit CL、补丁、独立验证、发布通道、终端生效证据和回退条件；WebGPU 优化须同时通过推理性能与前台帧率门禁。
