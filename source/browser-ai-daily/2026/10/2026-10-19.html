Browser Self-Improvement

Capability Contract + Independent Oracle

业界做到哪：已合并的 SUM 修复走过 Regression → Diagnose → Patch → Cross-Backend Test → Review/Merge；Agent 辅助的 argsort/top-k、Metal NORM 和 Vulkan Fusion 仍是待审查候选。尚无自动 Canary、Telemetry 回流与持续学习的证据。

Telemetry / WPT / Kernel Failure
  ↓ Minimize Counterexample (slice / stride / shape)
  ↓ Validate Capability Contract
  ↓ Agent Patch + Regression Test
  ↓ Build / Numerical Oracle / Cross-GPU Benchmark
  ↓ Review → Canary → Archive → Learn

迁移方案：在 Chromium/Dawn 选择 SUM、NORM、MatMul，自动生成连续、转置、切片、带 stride 输入；以 CPU 参考输出验证数值。保存 Browser Revision、GPU Adapter/Driver、WGSL、最小反例和验证结果。Agent 可改进候选生成和测试覆盖，但不得自行降低批准自身补丁的数值阈值。

今天的一个判断

Browser Self-Improvement 的价值不是让 Agent 生成更多 Kernel，而是让每个 Kernel 的能力声明都能被反例挑战，再由独立验证决定是否进入主线。
