今天最值得看

1. Firefox 158：Smart Window 从相关标签页与已保存信息建议表单填写（10 月 13 日）

Firefox Smart Window 现在可在用户点击表单字段、或主动选择 Fill from sources 时，根据相关的打开标签页和自动填充数据建议内容。此功能逐步推出，并非所有用户均已开启。工程启发：浏览器 Runtime 应明确区分信息来源、用户确认、权限决定和实际填写；模型可以推荐内容，不能因为能读取一个标签页就获得跨站操作权限。

Firefox 158 官方发布说明

2. Firefox 158：Resource Timing 支持 HTTP 缓存来源，Network Monitor 修复 WebSocket 漏报（10 月 13 日）

Firefox 新增 PerformanceResourceTiming.deliveryType 的 cache 值；开发者工具修复了 WebSocket 建连后立即到达的消息可能漏报的问题。工程启发：Browser Agent 诊断网络与页面性能时，需要区分缓存命中、真实网络事件和 DevTools 观测完整性。不要把工具漏报当成网络故障。

MDN Firefox 158 开发者说明

3. Chrome 155：桌面安全更新包含 37 项修复、7 项 Critical（10 月 13 日）

Windows/macOS 版本更新到 155.0.8059.79/.80，Linux 更新到 155.0.8059.79。官方公告列出 37 项修复，其中 7 项为 Critical，涉及图形、浏览器核心、PDF、网络、SVG、媒体等组件。部分问题细节尚未公开。工程启发：安全问题应尽量形成可复现输入、版本定位、回归测试和独立验证记录；修复数量不等于 AI 自动修复能力。

Chrome 官方公告 · 公开发布索引

4. Firefox 158：JIT、WASM、Canvas 与隔离边界修复值得纳入回归集（10 月 13 日）

Mozilla MFSA 2026-106 公告涵盖 JavaScript JIT、WebAssembly、Canvas2D、网络隔离等模块的安全修复；其中若干问题由 OpenAI 研究人员 Amy Burnett 报告。公告没有逐项披露 AI 参与发现的程度，不能直接称为 AI 自主漏洞发现。工程启发：把公开问题对应的最小复现、修复版本和安全回归测试长期保留，避免未来优化引入同类缺陷。

Mozilla MFSA 2026-106

5. Web$hell：把网页编译为可寻址信息与操作对象（10 月 9 日，补推）

论文提出 WebContract 统一网页信息与操作描述，WebCompiler 转换实时页面，WebCache 维护可复用对象，以支持搜索、导航和深度研究。作者报告任务表现和成本优势，但尚需真实浏览器独立验证。工程启发：缓存的动作必须绑定 origin、frame、session、页面版本和权限，命中后仍检查实时页面状态。

Firefox 安全公告

浏览器 × AI

Firefox Smart Window 展示了浏览器已有会话信息参与具体任务的产品路径；Web$hell 展示了可复用信息/操作接口。二者结合时，Browser Runtime 负责会话、身份和权限，Agent 提供建议，缓存降低重复理解成本，最终操作必须经过实时状态与用户授权检查。

Smart Window · Web$hell

Browser Self-Improvement

Security Reproducer as a Durable Asset：把真实问题转化为长期可执行回归测试

业界做到哪：Chrome 与 Firefox 已完成多组件安全修复并发布 Stable，覆盖 Finding → Patch → Release；Firefox 的 Resource Timing 与 WebSocket DevTools 修复改善 Observe。公开材料没有证明这些问题全部由 Agent 自动复现、修补、Canary 和学习，不能视为完整自动闭环。

迁移建议：为每条可公开问题保留 browser_sha、harness_sha、最小输入、复现环境、预期输出、culprit CL 和验证结果。先从 JIT/WASM、Canvas/图形、Network/隔离选取公开案例做小规模回归集。Agent 可以优化复现和实验选择，但不得修改独立的验收标准；无法稳定复现的问题先补证据，不直接投入昂贵构建。

Mozilla 公告 · Chrome 公告

开源与论文 / 工程实践

Web$hell 值得作为 Browser Harness 实验接口：比较原始 DOM 与结构化缓存两种路径的任务成功率、token 成本、P95 延迟、页面变化后的误操作率与权限拒绝正确性；不能把论文指标直接当成产品实测。

Web$hell 论文 · Firefox 开发者更新

今天的一个判断

Browser Self-Improvement 的长期价值，不在于发现更多问题，而在于把一个真实问题永久转化为能够自动发现同类回归的测试资产。 只有保存可复现输入、环境、版本和独立验证结果，后续 Agent 生成的 Patch 与 Learn 才有可靠依据。
